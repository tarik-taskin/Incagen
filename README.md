# Incagen

Incagen, işletme belgelerinden yapay zekâ destekli analizler ve uygulanabilir büyüme önerileri üretmek üzere hazırlanan bir web uygulamasıdır.

## Teknolojiler

- React 19 ve TypeScript
- Vite 6
- Tailwind CSS
- shadcn/ui yaklaşımı ve Radix UI
- Anime.js

## Geliştirme

```bash
npm install
npm run dev
```

Üretim derlemesi ve kod kalite kontrolleri:

```bash
npm run build
npm run lint
```

Ana sayfadaki belge alanı şimdilik yalnızca görsel ve PDF dosyaları için sistem dosya seçicisini açar. Yükleme veya analiz işlemi henüz bağlı değildir.
